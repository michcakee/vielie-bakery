# Content rating notes

Answers for the IARC questionnaire (Google Play) and the App Store age rating, based on the game as built. Expected result: **Everyone / PEGI 3 / 4+**.

| Topic | Answer |
| --- | --- |
| Violence, blood, fear | None |
| Sexual content, nudity | None |
| Profanity or crude humour | None |
| Drugs, alcohol, tobacco | None (coffee and tea only) |
| Gambling | **No.** No wagering and no loot boxes: diamond packs always give a fixed, stated number of diamonds, and each Dream team character costs a fixed, stated number. The game simulates business risk (loans, marketing that may or may not pay off, co-op shares) with in-game money only. |
| Simulated gambling | No |
| User-generated content / chat | None. Players can name their bakery; the name never leaves the device. |
| Sharing location | No |
| Digital purchases | **Yes (iOS app):** optional consumable diamond packs ($0.99, $2.99, $5.99). Nothing random. Diamonds are also earned free on 3-star days. Answer "In-App Purchases: Yes" in App Store Connect. |
| Ads | None |
| Data collection | None (see [PRIVACY_POLICY.md](PRIVACY_POLICY.md)) |
| Unrestricted web access | No |
| Educational content | Yes: plain-language business and economics concepts |

**Apple "Made for Kids":** not opted in. The game is suitable for children but isn't specifically designed for under-12s, and opting in adds review requirements.
